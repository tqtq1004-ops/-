# Nudif Salon Dashboard

누디프 살롱 운영을 위한 단일 페이지 대시보드입니다. 매출, 예약, 재고, 데이터 가져오기와 마감 기능을 브라우저에서 사용할 수 있습니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리와 글꼴은 인터넷 연결 시 자동으로 불러옵니다.

## GitHub에 올리기

1. GitHub에서 비어 있는 새 저장소를 만듭니다.
2. 이 폴더의 파일 전체를 저장소에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포할 브랜치와 `/ (root)` 폴더를 선택합니다.
4. 안내되는 주소에서 대시보드를 엽니다.

GitHub Pages에서 정적 웹사이트로 바로 배포할 수 있습니다.

## 파일 구성

- `index.html`: 화면, 스타일, 동작을 모두 담은 대시보드
- `.gitignore`: 운영체제·개발 도구의 불필요한 파일 제외 목록

## 참고

화면은 GitHub Pages, 저장 API는 Vercel, 원본 데이터는 MongoDB Atlas의 `nudif_dashboard.state` 컬렉션 (`_id: main`)을 사용합니다. localStorage는 기기별 캐시와 이전 데이터 복구용입니다. 서버 인증 없이 저장 성공으로 처리하지 않습니다.

## 백업·복구

- 설정 → 서버 데이터 백업 → 백업 내려받기: 현재 서버 원본을 JSON으로 내려받습니다. 비밀번호는 포함하지 않지만 고객·정산 정보가 포함될 수 있으므로 공개 저장소에 올리지 마세요.
- 수동 백업이며 자동·장기 이력 백업은 아닙니다. 중요한 수정 전에 별도 보관하세요.
- 복구 전 현재 서버도 백업하고, 백업의 `state.close` 월별 금액·상태를 현재 서버와 비교합니다. 다른 기기 편집을 중단한 뒤 필요한 월만 승인받아 병합해야 합니다. 파일 전체를 곧바로 덮어쓰지 마세요.
- 기존 공개 코드의 정산 기본값은 제거했습니다. 과거 Git 기록이나 이미 다운로드된 사본까지 삭제되는 것은 아닙니다.

## 보안 운영 확인

- `DASHBOARD_SYNC_KEY`가 없거나 공백이면 API 접근을 차단합니다. 실제 키는 충분히 긴 무작위 값으로 설정하고 모든 기기에서 재연결해야 합니다.
- 인증 실패는 실행 인스턴스별/IP별 15분에 10회까지 허용합니다. 재시작·여러 인스턴스·IP 변경으로 우회 가능하므로 Vercel 방화벽의 분산 요청 제한을 대체하지 않습니다.
- MongoDB 계정은 해당 데이터베이스에 필요한 최소 권한만 부여해야 합니다. 실제 계정 권한·비용·방화벽 설정은 관리 계정 로그인 후 별도 확인합니다.
- 사진 AI 인식은 종료되어 해당 API는 외부 AI 호출 없이 410을 반환합니다.
